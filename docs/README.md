# Documentation

The documentation site of weebo-kura, published at
<https://batleforc.github.io/weebo-kura>: [Fumadocs](https://fumadocs.dev) on
Next.js, exported statically, in the format the weebo operators share
([`@weebo/operator-docs`](https://github.com/weebo-si-operator/weebo-operator-kit/tree/main/packages/operator-docs),
the kit release's tarball in `package.json`).

```sh
task docs         # dev server on http://localhost:3000
task docs:build   # lint, type-check, static export to docs/out
task docs:gen     # resource reference pages from deploy/crd (also run by task recu)
```

| Path | What it holds |
| --- | --- |
| `content/docs/` | The pages, in MDX: concepts, guides, reference |
| `content/docs/crds/`, `public/crd-schemas/` | Generated by `weebo-crd-docs` from `deploy/crd/` (kura-crdgen): never edited by hand |
| `crd-docs.config.mjs` | The generator's input: examples, order, guides per kind |
| `src/lib/` | The site's name (`shared.ts`), the builder's choices, the IDE's recipes |
| `RFC/` | The design documents, as written; the site's Design page lists them |
| `api/openapi.json` | The OpenAPI document (`task dump-spec`), read by the console's build |

Every push to `main` that touches the site redeploys it (`.github/workflows/docs-pages.yml`);
CI builds it on every pull request.
