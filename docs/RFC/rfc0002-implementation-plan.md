## Divergences

| # | Phase | RFC section | Divergence | Reason |
| --- | --- | --- | --- | --- |
| D1 | 1 | §6.1, §10.2 (`503 unavailable` when the semaphore is full) | A full replica answers `429 rate_limited` with `Retry-After: 1` | A 503 lands in `kura_unavailable_total`, which `KuraDependencyFailing` pages on: a busy replica is not a failing dependency. Both clients already wait out a 429 |
| D2 | 2 | §7.1 T5 ("a wrong record fails the file") | A forged record is dropped and the chunk read again by the single route, whose answer `download()` checks as before | The file is never written from unchecked bytes either way; dropping keeps one hostile record from failing a file a single read can still fetch |
| D3 | 1–2 | §14 test names | T1–T5 are folded into existing tests (`prefix_token_cannot_fetch_outside_chunk_or_read_renamed_history`, `config_namespace_hidden_from_other_member`, `batches_answer_in_order_within_their_budget`, engine `a_batched_pull_makes_no_single_reads_and_drops_forged_records`) instead of tests of their own | Each reuses its suite's setup (a prefix token, a configuration space); the assertions carry the RFC's names |
| D4 | 2 | §7.5 ("200 rows per hash at most") | `sees_contents` keeps 200 rows per hash with `row_number()` after one set-based join, so the database reads every revision naming the asked contents before keeping 200 | A per-hash `unnest … CROSS JOIN LATERAL (… LIMIT 200)` was tried: 6 ms for 1,000 hashes with fresh statistics, but on a vault just pushed (stale statistics, the first attach's case) its nested loops scanned every revision per hash: 11.8 s for 50 hashes, past the 5 s statement timeout. The set-based form ran the 10,000-note attach in 33 s. The rows read are bounded by the vault's revisions naming those contents |
| D5 | 2 | §3 | Known limit, unmeasured: the batch path tops out at 60 × 4 MiB = 240 MiB a minute per device, below what 600 single reads a minute give for files of 1–16 MiB | Small notes are the case decision 42 measured; revisit if a vault of large files attaches slowly |
